# Security policy

Do not report real CVs, profile files, databases, reports, CSV exports, credentials, or applicant details in a public issue.

For a security concern involving the skill or tracker, use GitHub's private vulnerability reporting feature for this repository when available. Include a minimal reproduction with synthetic data.

The skill treats web content as untrusted data, fails closed on eligibility/funding/deadline uncertainty, and does not authorize application submission or access-control bypasses.
